## Como aprendo e construo

| Etapa | Pergunta que guia o trabalho |
| :---: | :--- |
| **01** | Qual problema estou tentando resolver? |
| **02** | Como posso dividir a ideia em partes menores? |
| **03** | O que preciso testar para validar a solução? |
| **04** | Como posso documentar o que aprendi? |
